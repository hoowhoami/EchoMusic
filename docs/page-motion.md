# EchoMusic 页面动效规范

动效用来说明页面、内容和操作状态的变化。保持音乐播放和连续操作的响应速度，已有布局、12px 浮层圆角及抽屉安全间距独立于动画。

## 节奏与层级

统一变量定义在 `src/renderer/motion.css`，由全局样式导入。

| 场景               | 进入 / 变化 | 退出             | 视觉方式                                   |
| ------------------ | ----------- | ---------------- | ------------------------------------------ |
| 页面导航           | 220ms       | 保留现有路由语义 | 纯透明度；不平移、缩放或模糊整页           |
| 内容区块           | 220ms       | 无延迟           | 6px 上移 + 淡入；32ms 错峰，累计不超过96ms |
| Drawer             | 240ms       | 140ms            | 16px 方向位移 + 淡入；遮罩180ms            |
| Dialog             | 180ms       | 140ms            | 纯淡入淡出，保持文字清晰                   |
| Popover / 日期弹层 | 180ms       | 120ms            | 沿实际展开方向移动4px；退出淡出            |
| Tooltip            | 120ms       | 120ms            | 淡入淡出；保留原有悬停等待与键盘触发规则   |
| 标签选中滑块       | 180ms       | —                | 原有 transform 滑动                        |
| 按钮反馈           | 120ms       | —                | 颜色与现有按压反馈，显式指定过渡属性       |

进入使用 `--motion-ease-enter` 快速起步、缓慢停稳；状态切换使用 `--motion-ease-standard`；退出使用 `--motion-ease-exit`。不采用弹簧回弹、连续呼吸或整页景深效果。

## 页面接入

- 路由继续使用 MainLayout 现有 CSS 动画、YzsKeepAlive 和缓存键；动画统一挂在已有内容视口，使多根节点页面也可入场；不为动画重建页面，不等待退场后才请求数据。页面插件仍可覆盖原有 `--page-transition-*` 和动画名。
- 首页已接入 `motion-section-enter`，用于标题、入口卡片组和推荐区块。新页面按同样粒度显式接入；用 `style="--motion-order: 1"` 指定顺序，最大延迟由公共样式限制。
- 区块动画在 DOM 插入时执行。缓存页恢复不强制重播区块，列表翻页、滚动和虚拟节点复用不添加逐行入场。
- 不给包含 sticky / fixed 后代的容器添加位移动画。首页的区块没有此类定位；页面根保持纯透明度。
- 加载骨架、错误、空态继续按真实状态即时显示；不为完成动画延迟错误反馈或数据呈现。

## 内容切换与异步列表

- 共享 `TabsContent` 对激活面板执行180ms纯淡入，覆盖收藏、历史、已购和使用该组件的详情页；原有隐藏/卸载策略保持不变，旧面板立即隐藏，不添加退场等待。
- 探索、搜索的条件内容面板接入同一 `motion-content-enter`。错误、空态和加载提示继续即时显示。
- `VirtualGrid` 与 `SongList` 在实际内容根进入时整组淡入，非活跃状态跳过。追加分页、排序和滚动不会重新创建该根，也不添加逐行动画。
- 标签下划线保持24px固定宽度，使用scaleX/opacity显隐；不再用宽度过渡触发布局。键盘方向键、焦点、ARIA关联不变。
- 样式只在 `prefers-reduced-motion: no-preference` 下启用；动画不使用forwards，不残留透明度或位移状态。

## 性能与交互约束

- 入场只变化 opacity 与 transform / translate，不动画化 width、height、top 或 filter。侧栏宽度是既有布局过渡，沿用并统一节奏，减少动态效果时立即更新。
- 不设置常驻 will-change，不使用 forwards 保留区块合成状态；动画结束后区块恢复正常样式。
- Popover 的独立 translate 不覆盖 Reka 的定位 transform，方向跟随碰撞处理后的 data-side。入退场交给 Reka Presence，避免 Vue Transition 落在外层定位节点而取不到方向变量。
- Drawer 关闭时立即禁用点击与焦点；可见性隐藏等待退出结束。Dialog 继续使用原有堆栈、Presence 和焦点恢复。
- 快速切换可以中断动画；不增加锁定、重复挂载、长列表观察器或逐帧布局测量。

## 减少动态效果

遵循系统 `prefers-reduced-motion`：跳过区块、页面和浮层的装饰动画；标签、按钮和侧栏即时更新。加载状态的必要指示器保持可辨认，不用全局 `* { animation: none }` 破坏播放/加载反馈。

系统偏好在运行期间改变时，MainLayout 会清理当前入场标记和待执行入场任务，不依赖已经不会触发的 animationend；恢复普通模式时只对下一次导航执行动画。

## 路由动画的中断与收尾

`usePageEntryMotion` 管理内容视口的入场状态，不接管路由组件或缓存。重播前先提交旧类的移除并查询样式，再添加新类，避免快速导航复用尚未结束的动画；没有逐帧轮询或布局尺寸测量。

清理依据浏览器返回的视口自身CSS动画及其 `finished` Promise，不依赖固定动画名。并行动画全部结束或取消后清理；缺少动画CSS时立即清理。子元素动画、CSS transition，以及开始观察时已暂停、零速或无限时长的效果不参与等待。插件入场应使用有限、正常播放的CSS动画，循环装饰放在子元素中。

每次导航、停用、减少动画偏好变化、插件动画名变化及卸载都会撤销上一轮回调权限，旧动画的迟到完成不会清掉新动画。切换配置只终止当前入场，不自动重播已经可见的页面。

实现参考：[Element.getAnimations](https://developer.mozilla.org/en-US/docs/Web/API/Element/getAnimations)、[Animation.finished](https://developer.mozilla.org/en-US/docs/Web/API/Animation/finished)。

## 验收范围

- 相关路由、日期、Dialog 堆栈、Tooltip 和按钮语义回归；针对偏好切换与快速导航增加生命周期测试。
- 使用真实共享组件验证展开方向、快速关闭/重开、焦点恢复、结束后的透明度/位移和 DOM 清理。
- 浏览器组件预览不能替代完整 Electron、高 DPI、低端设备、真实长列表及操作系统偏好的实机验收。

参考：[web.dev 动画性能](https://web.dev/articles/animations-guide)、[Vue Transition](https://vuejs.org/guide/built-ins/transition.html)、[MDN 减少动态效果](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)。

## 滚动与返回顶部

- 歌曲定位始终即时跳转：虚拟列表索引定位、目标位置计算和后续可见区域校正均使用 `instant`，不受系统动画偏好影响，列表容器不启用CSS平滑滚动。
- 共享滚动条轨道点击和显式平滑滚动通过 `resolveScrollBehavior` 在每次操作时读取系统偏好；减少动态效果时使用 `instant`，避免 `auto` 仍继承目标的平滑滚动CSS。不增加每个组件的媒体查询监听器。
- 显式 `auto` / `instant`、滚动目标计算、拖动滑块和缓存恢复契约保持不变。根节点的CSS平滑滚动仅在普通模式生效。
- 返回顶部始终即时回到0，长列表也不等待浏览器平滑滚动；按钮仅保留120ms淡入淡出，减少动态效果时无过渡，图标悬停位移2px。动画挂在实际DOM容器，避免共享Button的Tooltip多根节点使Vue Transition失效；退出容器禁用点击。零阈值有效。
- 此策略覆盖共享页面滚动入口，不更改歌词逐行跟随、插件自定义滚动或其余详情页专用定位。

## 表单与选项反馈

输入框、选择器触发器和清除入口使用 `motion-control-feedback`，仅过渡背景、边框、文字、透明度与阴影，统一120ms；宽高和位置直接更新。选择器箭头旋转及菜单高亮沿用相同快节奏。CustomSelector / CustomPicker选项直接复用共享Button反馈，不用transition-all覆盖。系统减少动态效果时共用时长token归零。

CustomPicker继承共享Dialog的12px圆角，不再单独覆盖为24px。选择、清除、搜索、禁用、键盘及弹层关闭逻辑保持原样。

## 图片与歌曲卡片

Image、Avatar、Cover的透明度过渡统一使用 `motion-image-feedback`（180ms）；减少动态效果时共用token归零。通用Image的加载脉冲仅在普通模式启用；保留懒加载和封面回退接口，资源状态校验见下文。

SongCard背景、操作按钮和封面播放入口统一120ms反馈，显式过渡颜色、透明度及既有缩放，不过渡卡片宽高。减少动态效果时取消装饰性缩放；播放加载指示保留。键盘焦点进入卡片时与悬停一样显示操作按钮，不增加逐行入场。

## 头像加载状态

Avatar仅在有地址且图片仍加载时显示骨架；加载失败或没有地址时使用静态默认头像。地址切换会重置加载状态和Reka头像上下文，避免成功后清空地址仍沿用loaded状态而隐藏占位。尺寸、已有回退延迟及showSkeleton开关保持原有配置语义，延迟在新资源的上下文中重新计时。

## 图片资源切换与回退

Image / Cover按实际图片地址区分DOM节点；load/error必须来自当前节点，且节点src属性仍等于当前目标，才能更新状态。覆盖DOM更新前迟到事件、卸载节点事件以及A→B→A重复地址场景，不额外预加载或重复发起请求。

Cover切换主图时同步退出旧回退状态；主图失败后只在备用地址不同时继续加载。备用图与已失败主图相同则结束骨架并显示错误占位，避免没有新请求却一直等待。主题或插件更新备用图地址时仍按新资源加载。

## 缓存页面的滚动条生命周期

Scrollbar进入KeepAlive缓存时停止尺寸观察、自动隐藏计时和待执行测量，结束拖动并移除全局鼠标监听；后台DOM的滚动归零事件不再向页面回传。重新激活后恢复观察并测量当前尺寸，沿用页面原有滚动位置恢复逻辑。

同一帧的多次尺寸通知只安排一次测量，读取最后的尺寸。已卸载或暂停的组件不会因旧nextTick、ResizeObserver回调或内容ref更新重新连接观察器；恢复不重复注册监听。

PageScrollContainer同时暂停自身尺寸观察和窗口resize监听，使用激活序号废弃迟到的nextTick滚动恢复。吸顶层暂停每个条目的ResizeObserver/MutationObserver，返回后重新读取标题与祖先布局；后台条目变化只标记布局失效。提供者卸载时主动释放全部观察器，不依赖子组件稍后的注销顺序。恢复沿用浏览器滚动锚定，标题高度变化时保持正文相对阅读位置。

虚拟列表与网格共用测量激活状态：页面缓存或active=false时解除尺寸观察、停止滚动测量；网格保留最后有效宽度，忽略隐藏产生的零宽及旧节点通知。重新激活后在DOM更新完成时读取最新宽度，同帧合并可见范围计算，不增加逐项动画或平滑定位。

歌曲定位按请求代次管理：新请求取消旧校正，缓存、停用、加载、当前歌曲/列表/容器变化同步废弃旧请求；nextTick和下一帧执行前再次验证目标歌曲索引与容器。行可见性只查询当前SongList，避免其他列表的同歌曲影响定位。所有有效定位阶段仍为instant。

SongList右键菜单仅在打开时绑定全局点击、键盘、resize和scroll监听，并记录打开时的滚动容器及原overflow；关闭/卸载时解除监听和滚动锁，不覆盖期间外部改写的overflow。更换滚动容器会关闭旧菜单。页面缓存或停用时关闭菜单及添加歌单弹窗，取消播放状态计时与吸顶失效帧；恢复时同步最新播放状态，不重开浮层。

Popover的显式open/close和父级open更新会取消待执行的悬停计时；holdOpen开启时取消已排队的关闭，显式关闭仍有效。进入缓存时清除计时、关闭浮层并通知父级；隐藏/禁用/卸载后不接受迟到的打开操作。仅已挂载、打开的click浮层订阅外部mousedown，保留嵌套Portal分支判断。manual仍由父级open控制，缓存及禁用期间强制隐藏。

BackToTop缓存时解除scroll监听并隐藏按钮，恢复时按当前容器和最新threshold重新判断。缓存中的容器替换不会绑定隐藏节点，卸载后拒绝迟到重绑；阈值变化无需等待滚动，同一容器不重复绑定。即时回顶及120ms淡入淡出保持不变。

Tooltip通过Root内的无DOM生命周期组件调用Reka公开onClose，在缓存时同时取消内部悬停计时和已打开提示；外层拒绝缓存/卸载后的迟到打开事件。保留Root、触发控件和输入状态，不通过重新挂载来清理。恢复后使用新的悬停或键盘交互打开，继续继承父级TooltipProvider的禁用设置。

Dialog与Drawer共用缓存open门控：进入缓存先隐藏并请求父级关闭，缓存/卸载期间不接受内部打开操作。仍遵循受控状态，父级在缓存期间另行设置open=true会在返回后生效。Dialog的交互层级随门控关闭，沿用Presence退场后释放栈和模态资源；Drawer仅打开时监听Escape，尊重已preventDefault的键盘事件。

叠加浮层的Escape由当前最上层处理：Popover通过Reka的escape-key-down立即关闭并取消延迟计时，holdOpen及退场期间仍消费事件。Drawer只在没有Dialog/Popover Presence时参与关闭，并按实际z-index及同层DOM绘制顺序选择最上面的可见抽屉；退场尚未隐藏的抽屉继续阻挡下层，避免按键重复穿透。层级仅在按键时查询，不增加常驻观察器或逐帧测量。

滚动助手插件与宿主回顶按钮均为36px、箭头18px；插件复用宿主Tooltip替代原生title。插件的独立定位容器保留避让计算，内容按钮负责悬停/按下反馈，显隐仅120ms透明度过渡，退出期间不接受点击。减少动态效果时禁用显隐及反馈过渡，保留静态避让位移和原有滚动行为。插件源码位于相邻EchoMusicPlugins仓库。

滚动助手观察当前容器内部的DOM变化，分页追加或展开内容后重新判断底部距离。body新增无关浮层时仅检查变化分支，不从body递归查找整页。滚动/布局通知复用已排队的一次RAF，读取最新状态；停用时解除容器引用，旧点击回调不再执行滚动。

DatePicker使用相同缓存open门控，页面缓存或控件禁用时关闭日历，恢复后等待新的交互；禁用时清除按钮不可操作且不接受内部日期更新。日历Presence参与Drawer的Escape所有权判断，并消费自身Escape，关闭日历不连带关闭抽屉。退场禁点不依赖减少动态效果媒体查询。

Popconfirm将底层Popover的触发器打开、外部/Escape关闭及缓存关闭事件统一回传父级；父级主动改值不回声通知。确认和取消仅对仍打开的弹层生效，同一次关闭不会重复发送动作；禁用、确认禁用或加载期间不执行确认操作。

InputNumber的长按仅在交互有效期内运行：松开、移出、窗口失焦、达到上下限、禁用、缓存及卸载均停止计时并解绑临时window监听。每次新按压废弃旧回调，恢复页面或重新启用不自动续按。增减操作结束编辑态，随后blur不再写回旧草稿；正常编辑失焦仍提交，停用后的迟到blur不提交。鼠标增减仅响应左键。

InputNumber在安全整数范围内按输入值与步长的最大小数位进行缩放加减，消除常见十进制步长尾数，保留更细输入精度及科学计数步长；超出安全缩放范围沿用Number计算，并仅提交有限数值。缺省无限边界不再作为无效值的计算起点，非法步长禁止增减。Enter同步提交编辑值后继续向父级传递事件，后续blur不重复提交；输入法组合期间不处理快捷键。歌单排序页面原有主动blur保护保留。

Select搜索词变化时同步重置虚拟列表范围和实际滚动位置（instant）；选项缩短时限制滚动范围，虚拟窗口不越过现有数据。搜索框Escape关闭菜单但不改选择，输入法组合期间保留Escape；关闭清空临时搜索词并恢复已选项显示。nextTick聚焦和宽度测量执行前复查open/disabled，避免关闭或禁用后的旧任务抢焦点。

Input的清除入口与输入限制一致：禁用、只读或关闭showClear时隐藏按钮，并在动作执行时再次检查；祖先fieldset禁用时也拒绝清除。显式判断空值使数值0可清除。按钮使用可访问名称、保留type=button，清除后通过preventScroll聚焦输入框，保持键盘编辑连续且不引入滚动。原有update:modelValue与clear事件、输入属性和键盘监听透传保持不变。
