# 全局歌词时间校准

在「设置 → 页面歌词 → 全局歌词时间偏移」中输入秒数，确认输入或移出输入框后生效。

- 默认 0 秒；支持 -10 到 +10 秒，输入框步长为 0.1 秒。
- 正数让歌词提前，负数让歌词延后。例如歌词普遍慢 0.4 秒，可以设为 +0.4。
- 对所有歌曲生效，切歌和重启后保留；不修改音频播放时间、歌曲文件或原始歌词时间戳。
- 有效偏移 = 全局校准 + 当前歌曲微调。原有单曲微调值保留，每个范围独立限制为 ±10 秒。
- 歌词页、桌面歌词及插件已有的微调/重置命令仍只修改当前歌曲；「重置全局」只清除全局校准。
- 页面歌词（包括逐字、AMLL）、桌面、Mini 和任务栏/插件快照共用有效偏移。第三方插件如果绕过应用歌词时间轴自行计时，需要自行使用快照中的 `timeOffset`。

本功能对应 Issue #438 中的全局歌词进度需求，不包含该 Issue 提到的 CPU 多线程或插件性能改造。
